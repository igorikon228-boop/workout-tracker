# 4 недели силы — v30

Персональный PWA-трекер четырёхнедельной программы тренировок.

## Возможности

- Стартовый тест: имя, максимум отжиманий, приседаний и планки.
- Автоматическая программа на 28 дней от стартовых показателей.
- Режим тренировки с подходами, таймерами и переходами.
- «План» со всеми 28 днями и общей шкалой прогресса.
- «Чтиво» со статьями про воду и 5 известных спортсменов.
- «Профиль» со статистикой, целью и достижениями.
- Установка как PWA на GitHub Pages.

## Навигация

**Тренировка / План / Чтиво / Профиль**

Достижения находятся внутри профиля. «Общий прогресс» отображается только в «Плане».

## Профиль v29

- Убрано пояснение о подсчёте статистики.
- «Твои ориентиры» заменены на **«Цель»**.
- В цели показываются только конечные значения: отжимания, приседания и планка.
- Стартовые показатели и подпись `×1,5` в этом блоке не отображаются.
- Достижения и их прогресс остаются ниже.

## Интерфейс

Сверху — фирменная шапка с логотипом, wordmark **«4 НЕДЕЛИ / СИЛЫ.»** и компактной кнопкой сброса. На телефоне стартовый постер показывается полностью; шапка адаптирована и для экранов до 360 px.

## Надёжность v29

Добавлена безопасная проверка карточки общего прогресса: изменение её разметки больше не должно останавливать запуск приложения из-за обращения к отсутствующему DOM-элементу.

## PWA

Service Worker cache: `workout-v30`.

Для GitHub Pages загружай содержимое архива прямо в корень репозитория — `index.html` должен лежать в корне.


## Режим тренировки v30

Интерфейс прохождения упражнений упрощён по обратной связи:

- раздел «Сегодня» переименован в **«Тренировка»**;
- на карточке тренировки запись нагрузки стала понятнее: например, `4 подхода × 8 повторений`;
- в режиме тренировки **подход и повторения больше не объединены в одну строку**;
- сверху показывается общий номер текущего упражнения;
- отдельно крупно показываются **«Подход 2 из 4»** и **«Повторения 8»**;
- для планки вместо повторений показывается **время**;
- основная кнопка сформулирована как **«Начать подход» / «Подход выполнен»**;
- во время отдыха явно показано следующее упражнение, номер его подхода и целевая нагрузка;
- второстепенные действия визуально отделены от основной кнопки.

Логика круговой тренировки и 35-секундных переходов сохранена.
