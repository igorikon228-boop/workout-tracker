# 4 недели силы — v19

- стартовое изображение полностью помещается на мобильном экране без обрезки;
- исправлен таймер тренировки: одновременно существует только один активный timeout;
- пропуск подготовки, упражнения или отдыха отменяет предыдущий timeout;
- у полученных достижений больше нет надписи «Получено» и галочки;
- заблокированное достижение по-прежнему отмечается замком.
