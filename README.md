# 4 недели силы — v26

Персональный PWA-трекер четырёхнедельной программы тренировок.

## Что есть в приложении

- Стартовый тест: имя, максимум отжиманий, приседаний и планки.
- Автоматическая программа на 28 дней с нагрузкой от текущих показателей.
- Режим тренировки с подходами, таймерами и переходами между упражнениями.
- Раздел «План» со всеми 28 днями и шкалой общего прогресса.
- Раздел «Чтиво» со статьями про воду и 5 известных спортсменов.
- «Профиль» со статистикой, целями и достижениями.
- Достижения за тренировки, повторения и прохождение каждой недели.
- Работа как устанавливаемое PWA на GitHub Pages.

## Навигация

Главное меню состоит из четырёх разделов:

**Сегодня / План / Чтиво / Профиль**

Достижения находятся внутри «Профиля».

## Интерфейс v26

В верхней части приложения добавлена фирменная шапка:

- слева — логотип приложения;
- справа — название **«4 недели силы»**.

Шкала «Общий прогресс» отображается только в разделе «План».

## PWA

Версия кэша Service Worker: `workout-v26`.

Для публикации на GitHub Pages содержимое архива нужно загрузить непосредственно в корень репозитория, чтобы `index.html` находился в корне.
